درس ۱: عددهای گویا
۱
عددهای گویا و نمایش اعشاری
پایه‌ی فصل دوم
عدد گویا: هر عددی که به‌صورت کسر a/b نوشته شود که a, b ∈ Z و b ≠ 0.
Q = { a/b | a, b ∈ Z , b ≠ 0 }
هر عدد صحیح، یک عدد گویا هم هست: Z ⊆ Q
انواع اعشار
  • اعشار مختوم: تعداد رقم‌های اعشاری محدود است. مثال: ۰/۵ ، ۰/۲۵ ، ۳/۷۵
  • اعشار متناوب: یک یا چند رقم مرتب تکرار می‌شوند. مثال: ۰/۳۳۳... ، ۰/۱۶۶۶... .
  • اعشار نامتناوب: نه مختوم، نه متناوب. مثل π و √۲ (این‌ها گنگ هستند).
شرط مختوم بودن اعشار
اگر یک کسر را ساده کنیم، اعشارش مختوم است اگر و تنها اگر مخرج ساده‌شده فقط شمارنده‌ی اول ۲ و ۵ داشته باشد:
مخرج = 2ᵃ × 5ᵇ
مثال: ۷/۲۰ = ۷/(2²×5) → مختوم ✅
مثال: ۵/۱۲ = ۵/(2²×3) → متناوب ❌ (چون ۳ دارد)
تبدیل اعشار به کسر
  • اعشار مختوم: از مخرج‌های ۱۰، ۱۰۰، ۱۰۰۰ استفاده کن.
    مثال: ۰/۲۵ = ۲۵/۱۰۰ = ۱/۴
  • اعشار متناوب: با ضرب در ۱۰، ۱۰۰، ... معادله حل کن.
    مثال: ۰/۳̄ = ۱/۳
نکته‌ی مهم: بین دو کسر بی‌شمار کسر
بین هر دو کسر متمایز، بی‌شمار کسر وجود دارد. برای پیدا کردن کسر بین دو کسر:
  • روش ۱: مخرج را بزرگ‌تر کن.
  • روش ۲: میانگین دو کسر را بگیر: (a/b + c/d) ÷ 2
درس ۲: عددهای حقیقی
۲
عددهای گنگ و حقیقی
نقشه‌ی کامل انواع اعداد
عدد گنگ (Q′): عددی که گویا نیست و نمی‌توان آن را به‌صورت a/b نوشت. اعشارش نه مختوم است، نه متناوب.

عدد حقیقی (R): مجموعه‌ی همه‌ی عددهای گویا و گنگ:
R = Q ∪ Q′
نقشه‌ی مجموعه‌های اعداد
N ⊆ W ⊆ Z ⊆ Q ⊆ R
Q′ ⊆ R
💡 نکته‌ی مهم: Q ∩ Q′ = ∅ — چون هیچ عددی نمی‌تواند هم گویا باشد هم گنگ.
مثال‌های عدد گنگ
  • √۲ ≈ ۱/۴۱۴
  • √۳ ≈ ۱/۷۳۲
  • √۵ ≈ ۲/۲۳۶
  • π ≈ ۳/۱۴۱۵۹...
تشخیص گویا از گنگ
  • عدد صحیح یا کسر → گویا ✅
  • اعشار مختوم یا متناوب → گویا ✅
  • جذر یک مربع کامل → گویا ✅
    مثال: √۴ = ۲، √۹ = ۳، √۱۶ = ۴
  • جذر غیرمربع کامل → گنگ ✅
    مثال: √۲، √۳، √۵
  • π → گنگ ✅
⚠️ اشتباه رایج: فکر کنی هر عدد رادیکالی گنگ است. اشتباه!
  • √۴ = ۲ → گویا ✅
  • √۲۵ = ۵ → گویا ✅
  • √۲ → گنگ ✅
همیشه اول ببین زیر رادیکال، مربع کامل هست یا نه!
درس ۳: قدر مطلق و محاسبه‌ی تقریبی
۳
قدر مطلق، گرد کردن و تخمین
فاصله از صفر + محاسبه‌ی تقریبی
قدر مطلق: فاصله‌ی یک عدد از صفر روی محور اعداد. نماد: |a|
اگر a ≥ 0 : |a| = a  |  اگر a < 0 : |a| = −a
قدر مطلق همیشه نامنفی است.
خاصیت‌های قدر مطلق
  • همیشه نامنفی: |a| ≥ 0
  • قرینه: |a| = |−a|
  • ضرب: |a × b| = |a| × |b|
  • تقسیم: |a ÷ b| = |a| ÷ |b|
  • رابطه با جذر: √(a²) = |a|
حل معادله‌ی قدر مطلق
|x| = a (a ≥ 0) → x = a یا x = −a
  • مثال: |x| = ۵ → x = ۵ یا x = −۵
  • مثال: |x| = −۳ → بی‌جواب (∅)
  • مثال: |x − ۳| = ۵ → x = ۸ یا x = −۲
گرد کردن و قطع کردن
گرد کردن: به رقم بعدی نگاه کن:
  • اگر ≥ ۵ بود، یک واحد به رقم آخر اضافه کن.
  • اگر < ۵ بود، تغییر نده.
مثال: ۳/۷۸۶ به دو رقم اعشار → ۳/۷۹ (چون رقم بعدی ۶ است)

قطع کردن: بدون نگاه به رقم بعدی، فقط حذف کن.
مثال: ۳/۷۸۶ به دو رقم اعشار → ۳/۷۸

📍 درس ۱: عددهای گویا

  • Q = {a/b | a,b∈Z, b≠0}
  • Z ⊆ Q
  • اعشار مختوم و متناوب → گویا
  • شرط مختوم: مخرج فقط ۲ و ۵
  • بین دو کسر، بی‌شمار کسر

📍 درس ۲: عددهای حقیقی

  • Q′ = عددهای گنگ
  • R = Q ∪ Q′
  • N ⊆ W ⊆ Z ⊆ Q ⊆ R
  • Q′ ⊆ R
  • Q ∩ Q′ = ∅
  • √۲، √۳، π → گنگ
  • √۴، √۹ → گویا

📍 درس ۳: قدر مطلق

  • |a| = فاصله از صفر
  • همیشه نامنفی
  • |a| = |−a|
  • √(a²) = |a|
  • |x| = a → x = ±a
  • |x| = −a → ∅

📍 محاسبه‌ی تقریبی

  • گرد کردن: به رقم بعدی نگاه کن
  • رقم بعدی ≥ ۵ → بالا
  • رقم بعدی < ۵ → پایین
  • قطع کردن: بدون نگاه
  • تخمین: سریع‌تر از دقیق

الف) هر عدد صحیح، حقیقی است.

نکات طلایی امتحانی فصل دوم

⚠️ اشتباهاتی که نمره‌ات را می‌خورند

  • فکر کنی هر عدد رادیکالی گنگ است. (√4 گویاست!)
  • فکر کنی π گویاست. (اشتباه! π گنگ است)
  • در شرط مختوم بودن، اول کسر را ساده نکنی.
  • فکر کنی قدر مطلق می‌تواند منفی باشد.
  • در معادله‌ی |x| = −a بگویی جواب دارد. (بی‌جواب است!)
  • در گرد کردن، وقتی رقم بعدی ۵ یا بیشتر است، اضافه نکنی.
  • اشتباه گرفتن گرد کردن با قطع کردن.
  • در √(a²) = |a|، قدر مطلق را فراموش کنی.

🎯 ترفندهای سریع حل تست

  • برای تشخیص مختوم بودن: اول کسر را ساده کن، بعد مخرج را به شمارنده‌های اول تجزیه کن.
  • برای تشخیص گویا از گنگ: ببین رادیکال، مربع کامل است یا نه.
  • برای بین دو کسر: از میانگین استفاده کن.
  • در قدر مطلق: همیشه از خودت بپرس «فاصله از صفر چقدر است؟»
  • در گرد کردن: به رقم بعدی نگاه کن، نه رقم‌های بعدتر.

🎓 استراتژی روز امتحان

  1. قبل از شروع، یک بار کل برگه را نگاه کن.
  2. اول سؤالات آسان را حل کن، بعد سراغ سخت‌ها برو.
  3. در سؤالات مختوم بودن، اول کسر را ساده کن.
  4. در معادلات قدر مطلق، هر دو حالت را چک کن.
  5. در پایان، ۵ دقیقه‌ی آخر را به مرور جواب‌ها اختصاص بده.
