پیش‌نیاز ۱: فاصله روی محور اعداد
فرسام
آقای فرسام: سلام سروناز جان. قبل از تعریف قدر مطلق، بگذار یک مفهوم ساده را با هم مرور کنیم: فاصله.
سروناز
خانم سروناز: یعنی چقدر از هم دور هستند؟
فرسام
آقای فرسام: دقیقاً! حالا بگذار روی محور اعداد نشان بدهم. فرض کن دو عدد داریم: ۳ و ۷. فاصله‌ی این دو روی محور چقدر است؟
شکل ۱: فاصله‌ی دو عدد روی محور، تفاضل بزرگ‌تر منهای کوچک‌تر است
فاصله‌ی دو عدد روی محور: اگر دو عدد حقیقی داشته باشیم، فاصله‌ی آن‌ها برابر است با تفاضل بزرگ‌تر منهای کوچک‌تر (همیشه عددی نامنفی).
d(a, b) = |a − b|

مثال‌های فاصله

فاصله‌ی ۳ و ۷: 7 − 3 = ۴
فاصله‌ی ۲ و ۸: 8 − 2 = ۶
فاصله‌ی −۲ و ۵: 5 − (−2) = 5 + 2 = ۷
فاصله‌ی −۵ و −۱: (−1) − (−5) = −1 + 5 = ۴
فاصله‌ی −۳ و ۳: 3 − (−3) = ۶
پیش‌نیاز ۲: قرینه‌ی یک عدد
فرسام
آقای فرسام: سروناز جان، یک مفهوم دیگر را هم یادآوری کنیم: قرینه. قرینه‌ی عدد ۵ چیست؟
سروناز
خانم سروناز: −۵. چون قرینه یعنی هم‌فاصله از صفر ولی در طرف مخالف.
قرینه‌ی یک عدد: عددی که با عدد اصلی، فاصله‌ی یکسانی از صفر دارد ولی در طرف مخالف محور است. برای به‌دست آوردن قرینه، فقط علامت را عوض می‌کنیم.
قرینه‌ی 5 = −5   |   قرینه‌ی (−7) = 7   |   قرینه‌ی 0 = 0
💡 نکته: قرینه‌ی هر عدد حقیقی، خودش یک عدد حقیقی است. به‌طور کلی:
  • قرینه‌ی عدد مثبت، منفی است.
  • قرینه‌ی عدد منفی، مثبت است.
  • قرینه‌ی صفر، خود صفر است.
درس اصلی ۱: تعریف قدر مطلق
فرسام
آقای فرسام: حالا با تمام پیش‌نیازها، برویم سراغ مفهوم اصلی: قدر مطلق.
قدر مطلق یک عدد، فاصله‌ی آن عدد از صفر روی محور است.
قدر مطلق: قدر مطلق عدد a، فاصله‌ی آن عدد از صفر روی محور اعداد است. نماد آن دو خط عمودی است:
|a| = فاصله‌ی a تا صفر

به‌صورت ریاضی:
اگر a ≥ 0 باشد: |a| = a
اگر a < 0 باشد: |a| = −a
سروناز
خانم سروناز: فرسام جان، چرا برای عدد منفی، قدر مطلق می‌شود منفیِ خودش؟
فرسام
آقای فرسام: سؤال خیلی خوبی! ببین: اگر a = −5 باشد، فاصله‌ی آن از صفر برابر ۵ است.
اما خودِ a = −5 است. پس چطور به ۵ برسیم؟ باید قرینه‌اش را بگیریم:
|−5| = −(−5) = 5 ✅
پس قدر مطلق، همیشه عدد نامنفی است (بزرگ‌تر یا مساوی صفر).
شکل ۲: قدر مطلق ۵ و −۵ هر دو برابر ۵ است، چون هر دو ۵ واحد از صفر فاصله دارند
مثال‌های ساده

قدر مطلق اعداد را حساب کنید:

|7| = 7 (عدد مثبت، خودش)
|−7| = 7 (عدد منفی، قرینه‌اش)
|0| = 0 (صفر)
|3/4| = 3/4
|−3/4| = 3/4
|−2/5| = 2/5
|√5| = √5
|−√5| = √5
|1 − √2| = √2 − 1 (چون 1 − √2 منفی است، قرینه می‌شود)
⚠️ اشتباه رایج: بعضی فکر می‌کنند قدر مطلق هر عدد، همیشه خود عدد است.
نه! قدر مطلق، همیشه نامنفی است:
  • |۵| = ۵ ✅
  • |−۵| = ۵ ✅ (نه −۵!)
درس اصلی ۲: خاصیت‌های قدر مطلق
فرسام
آقای فرسام: قدر مطلق چند خاصیت مهم دارد که در حل مسائل به کارت می‌آید.
خاصیت‌های قدر مطلق:
  1. همیشه نامنفی است: |a| ≥ 0
  2. قدر مطلق صفر: |a| = 0 ⇔ a = 0
  3. قدر مطلق قرینه‌ها: |a| = |−a|
  4. قدر مطلق حاصل‌ضرب: |a × b| = |a| × |b|
  5. قدر مطلق حاصل‌تقسیم: |a ÷ b| = |a| ÷ |b| (به شرط b ≠ 0)
  6. رابطه‌ی جذر: √(a²) = |a|
مثال‌های خاصیت‌ها

۱) خاصیت |a| = |−a|

|7| = |−7| = 7 ✅
|5/2| = |−5/2| = 5/2 ✅

۲) خاصیت |a × b| = |a| × |b|

|(−3) × 4| = |−12| = 12
|−3| × |4| = 3 × 4 = 12 ✅
هر دو یک جواب دارند

۳) خاصیت √(a²) = |a|

√((−۵)²) = √۲۵ = ۵ = |−۵| ✅
√(۷²) = √۴۹ = ۷ = |۷| ✅
پس همیشه: √(a²) = |a|
💡 نکته‌ی مهم: قدر مطلق برای جذر گرفتن از توان دو استفاده می‌شود.
  • √((−۳)²) = √۹ = ۳ = |−۳| ✅
  • √((۳)²) = √۹ = ۳ = |۳| ✅
پس همیشه جواب نامنفی است.
درس اصلی ۳: حل معادلات قدر مطلق
سروناز
خانم سروناز: فرسام جان، اگر معادله‌ای داشته باشیم مثل |x| = ۵، چطور حل کنیم؟
فرسام
آقای فرسام: سؤال خوبی! یک قانون مهم داریم:
قانون حل معادله‌ی قدر مطلق:
|x| = a   (a ≥ 0)   →   x = a  یا  x = −a
یعنی دو جواب داریم: خود a و قرینه‌اش.
مثال‌های معادله

۱) |x| = ۷

x = ۷ یا x = −۷
جواب: {−۷، ۷}

۲) |x| = 0

فقط یک جواب: x = 0
جواب: {0}

۳) |x| = −۳

قدر مطلق هرگز منفی نمی‌شود.
پس این معادله هیچ جوابی ندارد.
جواب: ∅ (تهی)

۴) |x − ۳| = ۵

گام ۱: داخل قدر مطلق را برابر ۵ و −۵ قرار می‌دهیم:
حالت ۱: x − 3 = 5 → x = 8
حالت ۲: x − 3 = −5 → x = −2
جواب: {−۲، ۸}

۵) |2x + 1| = ۹

حالت ۱: 2x + 1 = 9 → 2x = 8 → x = 4
حالت ۲: 2x + 1 = −9 → 2x = −10 → x = −5
جواب: {−۵، ۴}
⚠️ اشتباه رایج: در حل معادله‌ی |x| = −۳، بعضی‌ها می‌گویند x = ۳ یا x = −۳. اشتباه است!
قدر مطلق هرگز منفی نمی‌شود. پس معادله‌ی |x| = −۳ هیچ جوابی ندارد.
درس اصلی ۴: محاسبه‌ی تقریبی و گرد کردن
فرسام
آقای فرسام: حالا برویم سراغ بخش دوم این درس: محاسبه‌ی تقریبی.
فرض کن عدد ۳/۷۸۶۴۲ را داری. اگر بخواهی آن را به دو رقم اعشار گرد کنی، چه می‌کنی؟
سروناز
خانم سروناز: باید ببینیم رقم بعدی چیست؟ اگر بزرگ‌تر از ۵ بود، بالا می‌رود.
فرسام
آقای فرسام: دقیقاً! به این کار می‌گوییم گرد کردن.
گرد کردن (Rounding): برای گرد کردن یک عدد به تعداد رقم مشخص، به رقم بعدی نگاه می‌کنیم:
  • اگر رقم بعدی ۵ یا بیشتر باشد: یک واحد به رقم آخر اضافه می‌کنیم.
  • اگر رقم بعدی کمتر از ۵ باشد: رقم آخر را تغییر نمی‌دهیم.
مثال‌های گرد کردن

۱) گرد کردن ۳/۷۸۶۴۲ به دو رقم اعشار

گام ۱: دو رقم اول اعشار: ۷۸
گام ۲: رقم بعدی: ۶ (بزرگ‌تر از ۵)
گام ۳: یک واحد به ۸ اضافه می‌کنیم → ۷۹
پاسخ: ۳/۷۹

۲) گرد کردن ۳/۷۲۳۴ به دو رقم اعشار

گام ۱: دو رقم اول: ۷۲
گام ۲: رقم بعدی: ۳ (کمتر از ۵)
گام ۳: تغییری نمی‌دهیم.
پاسخ: ۳/۷۲

۳) گرد کردن ۵/۹۷ تا یک رقم اعشار

یک رقم اول: ۹، رقم بعدی: ۷ (بزرگ‌تر از ۵) → ۹+۱ = ۱۰
پس رقم اعشار ۰ می‌شود و به عدد صحیح یک واحد اضافه می‌شود.
پاسخ: ۶/۰

۴) گرد کردن ۱۲۸۷ به نزدیک‌ترین صد

رقم صدگان: ۲، رقم بعدی (دهگان): ۸ (بزرگ‌تر از ۵)
پس ۲+۱ = ۳ و بقیه صفر می‌شوند.
پاسخ: ۱۳۰۰

۵) گرد کردن √۲ ≈ ۱/۴۱۴ به دو رقم اعشار

دو رقم اول: ۴۱، رقم بعدی: ۴ (کمتر از ۵)
پاسخ: ۱/۴۱
درس اصلی ۵: قطع کردن و رقم‌های باارزش
قطع کردن (Truncation)
قطع کردن: یعنی بخشی از ارقام را بدون هیچ محاسبه‌ای حذف کنیم.
تفاوت با گرد کردن: در قطع کردن، به رقم بعدی نگاه نمی‌کنیم.

مقایسه‌ی گرد کردن و قطع کردن

عدد: ۳/۷۸۹
گرد کردن به دو رقم: ۳/۷۹ (چون رقم بعدی ۹ است)
قطع کردن به دو رقم: ۳/۷۸ (فقط دو رقم اول را نگه می‌داریم)
گرد کردن دقت بیشتری دارد
رقم‌های باارزش (Significant Figures)
رقم‌های باارزش: رقم‌هایی از یک عدد که اطلاعات دقیق را نشان می‌دهند.
در شمارش رقم‌های باارزش:
  • همه‌ی رقم‌های غیرصفر، باارزش‌اند.
  • صفرهایی که بین رقم‌های غیرصفر هستند، باارزش‌اند.
  • صفرهایی که بعد از رقم اعشار می‌آیند، باارزش‌اند.
  • صفرهایی که فقط برای جاگذاری هستند، باارزش نیستند.

مثال: تعداد رقم‌های باارزش

۲۵/۴۳: ۴ رقم باارزش (۲، ۵، ۴، ۳)
۰/۰۰۳۲: ۲ رقم باارزش (۳ و ۲؛ صفرها فقط جاگذار هستند)
۱۰۲۰: ۳ رقم باارزش (۱، ۰، ۲؛ صفر آخر نامعلوم است)
۵/۰۰: ۳ رقم باارزش (۵ و دو صفر بعد از ممیز)
درس اصلی ۶: کاربرد در تخمین و مقایسه
فرسام
آقای فرسام: یکی از کاربردهای مهم محاسبه‌ی تقریبی، تخمین زدن است. مثلاً در خرید، به‌جای محاسبه‌ی دقیق، تخمین می‌زنیم.

مثال تخمین در خرید

فرض کن می‌خواهی ۴ تا کتاب بخری. قیمت هر کتاب:

  • کتاب اول: ۲۳٫۴۰۰ تومان
  • کتاب دوم: ۱۸٫۹۰۰ تومان
  • کتاب سوم: ۳۱٫۵۰۰ تومان
  • کتاب چهارم: ۲۷٫۲۰۰ تومان
گام ۱: هر قیمت را به نزدیک‌ترین هزار تومان گرد می‌کنیم:
۲۳، ۱۹، ۳۲، ۲۷ (هزار)
گام ۲: جمع تخمینی: 23 + 19 + 32 + 27 = ۱۰۱ هزار تومان.
گام ۳: جمع دقیق: 23400 + 18900 + 31500 + 27200 = ۱۰۱,۰۰۰ تومان.
تخمین خیلی نزدیک بود! این کار در ذهن سریع‌تر است

تمرین‌های جامع با حل گام‌به‌گام
۱ مقدار هر یک از عبارت‌های زیر را حساب کنید:

الف) |−۸|

ب) |۵/۶|

پ) |−۲/۳|

ت) |۰|

ث) |۳/۷ − ۴|

نمایش پاسخ
الف) |−۸| = ۸ (قرینه‌ی −۸)
ب) |۵/۶| = ۵/۶ (عدد مثبت)
پ) |−۲/۳| = ۲/۳ (قرینه)
ت) |۰| = ۰
ث) |۳/۷ − ۴|:
۳/۷ − ۴ = ۳/۷ − ۲۸/۷ = −۲۵/۷ (منفی)
پس قدر مطلق = ۲۵/۷
۲ معادله‌های زیر را حل کنید:

الف) |x| = ۹

ب) |x − ۲| = ۶

پ) |2x + ۳| = ۱۱

ت) |x| = −۵

نمایش پاسخ
الف) |x| = ۹: x = ۹ یا x = −۹ → {−۹، ۹}
ب) |x − ۲| = ۶:
حالت ۱: x − 2 = 6 → x = 8
حالت ۲: x − 2 = −6 → x = −4
جواب: {−۴، ۸}
پ) |2x + ۳| = ۱۱:
حالت ۱: 2x + 3 = 11 → 2x = 8 → x = 4
حالت ۲: 2x + 3 = −11 → 2x = −14 → x = −7
جواب: {−۷، ۴}
ت) |x| = −۵: قدر مطلق منفی نمی‌شود → جواب: ∅
۳ درستی یا نادرستی هر عبارت را با ذکر دلیل مشخص کنید:

الف) |−۳| = ۳

ب) |۵| = −۵

پ) |a| = |−a|

ت) √((−۷)²) = −۷

نمایش پاسخ
الف) درست ✅ — قدر مطلق −۳ برابر ۳ است.
ب) نادرست ❌ — قدر مطلق همیشه نامنفی است، پس |۵| = ۵ نه −۵.
پ) درست ✅ — این یکی از خاصیت‌های قدر مطلق است.
ت) نادرست ❌ — √((−7)²) = √49 = 7، نه −7. قدر مطلق همیشه نامنفی است.
۴ عدد ۱۲/۷۸۶۴ را در موارد زیر گرد کنید:

الف) یک رقم اعشار

ب) دو رقم اعشار

پ) نزدیک‌ترین عدد صحیح

نمایش پاسخ گام‌به‌گام
الف) یک رقم: ۱۲/۷، رقم بعدی ۸ → بالا می‌رود → ۱۲/۸
ب) دو رقم: ۱۲/۷۸، رقم بعدی ۶ → بالا می‌رود → ۱۲/۷۹
پ) عدد صحیح: ۱۲/۷۸۶۴...، رقم اول اعشار ۷ → بالا می‌رود → ۱۳
۵ با استفاده از خاصیت‌های قدر مطلق، حاصل هر یک را بنویسید:

الف) |−۵| + |۳|

ب) |−۵ × ۳|

پ) |−۸| ÷ |۲|

نمایش پاسخ
الف) |−۵| + |۳| = ۵ + ۳ = ۸
ب) |−۵ × ۳| = |−۱۵| = ۱۵
پ) |−۸| ÷ |۲| = ۸ ÷ ۲ = ۴
۶ با استفاده از قدر مطلق، حاصل √((۲ − ۵)²) را بنویسید.
نمایش پاسخ
گام ۱: ۲ − ۵ = −۳
گام ۲: (−۳)² = ۹
گام ۳: √۹ = ۳
یا مستقیم با خاصیت: √((2 − 5)²) = |2 − 5| = |−3| = 3
پاسخ: ۳
۷ بدون استفاده از ماشین‌حساب، تخمین بزنید که کدام بزرگ‌تر است: √۸ یا ۳؟
نمایش پاسخ
می‌دانیم √9 = ۳ و √4 = ۲.
پس √8 بین ۲ و ۳ است و کوچک‌تر از ۳.
پس ۳ بزرگ‌تر از √۸ است
۸ فاصله‌ی دو عدد −۳ و ۴ را با قدر مطلق بنویسید.
نمایش پاسخ
فاصله = |4 − (−3)| = |4 + 3| = |7| = 7
فاصله = ۷
۹ عدد ۰/۰۰۵۲۳ را به دو رقم باارزش گرد کنید.
نمایش پاسخ
دو رقم باارزش اول: ۵ و ۲.
رقم بعدی: ۳ (کمتر از ۵) → تغییر نمی‌دهیم.
پاسخ: ۰/۰۰۵۲
۱۰ اگر |x| = ۶ باشد، مقادیر ممکن x را بنویسید و روی محور نشان دهید.
نمایش پاسخ
x = ۶ یا x = −۶
هر دو ۶ واحد از صفر فاصله دارند.
جواب: {−۶، ۶}
جدول خلاصه و نکات امتحانی
مفهوم تعریف / نماد مثال
فاصله‌ی دو عدد d(a,b) = |a − b| |5 − 2| = 3
قدر مطلق فاصله از صفر روی محور |−5| = 5
قدر مطلق مثبت a ≥ 0 → |a| = a |3| = 3
قدر مطلق منفی a < 0 → |a| = −a |−3| = 3
خاصیت نامنفی |a| ≥ 0 |−3| = 3 ≥ 0
قدر مطلق قرینه |a| = |−a| |5| = |−5|
قدر مطلق ضرب |a×b| = |a|×|b| |−3×2| = 3×2
رابطه با جذر √(a²) = |a| √((−5)²) = 5
معادله قدر مطلق |x| = a → x = a یا x = −a |x| = 4 → x = ±4
معادله بی‌جواب |x| = −a → ∅ |x| = −3
گرد کردن رقم بعدی ≥ ۵ → بالا 3/785 → 3/79
قطع کردن حذف بدون نگاه به بعدی 3/785 → 3/78
«قدر مطلق، فاصله را اندازه می‌گیرد — و فاصله هرگز منفی نیست.»
⚠️ شش اشتباه رایج در این درس:
  1. فکر کنی قدر مطلق می‌تواند منفی باشد. (اشتباه! همیشه نامنفی است)
  2. در معادله‌ی |x| = −a بگویی جواب دارد. (بی‌جواب است!)
  3. در گرد کردن، وقتی رقم بعدی ۵ یا بیشتر است، اضافه نکنی.
  4. اشتباه گرفتن گرد کردن با قطع کردن.
  5. در √(a²) = |a|، قدر مطلق را فراموش کنی.
  6. در شمارش رقم‌های باارزش، صفرهای جاگذار را بشمری.
💡 نکته‌ی طلایی: قدر مطلق همیشه یکی از این دو حالت است:
  • |a| = a اگر a نامنفی باشد (صفر یا مثبت).
  • |a| = −a اگر a منفی باشد.
این را با «فاصله از صفر» در ذهن نگه دار.
💡 نکته‌ی مهم درباره‌ی √(a²):
  • √((−۳)²) = √۹ = ۳ = |−۳| ✅
  • √((۲)²) = √۴ = ۲ = |۲| ✅
  • اشتباه رایج: √((−۳)²) = −۳ ❌ (چون جواب جذر همیشه نامنفی است)

سروناز
خانم سروناز: خب فرسام جان، امروز در این درس یاد گرفتیم:
  • قدر مطلق یعنی فاصله‌ی یک عدد از صفر روی محور.
  • قدر مطلق همیشه نامنفی است.
  • خاصیت‌های مهم: |a| = |−a| و √(a²) = |a|.
  • معادله‌ی |x| = a دو جواب دارد (a و −a).
  • معادله‌ی |x| = −a بی‌جواب است.
  • روش‌های گرد کردن و قطع کردن را یاد گرفتیم.
  • در تخمین زدن به‌کار می‌بریم.
