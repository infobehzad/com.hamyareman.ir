# School-books-9 — کتاب‌های پایه نهم (۱۳ کتاب)

## ساختار استاندارد هر درس (یکسان در همه‌ی کتاب‌ها)
```
<کتاب>/<فصل>/<درس>/
├── 00-تصاویر/             🖼 عکس‌های همه‌ی HTMLهای همین درس (منبع ساخت ماژول)
├── 01-جزوه_راهنما/        📄 جزوه‌ی آموزشی (HTML مصور)
├── 02-نکات_کلیدی/         📄 نکات کلیدی
├── 03-فلش_کارت/           🃏 کاردکس‌های مرور
├── 04-سوالات/             📝 بانک سوال
├── 05-پاسخ_سوالات/        🔑 پاسخ‌نامه
├── 06-پاسخ_تمرین_کتاب/    🔑 پاسخ تمرین‌های کتاب
├── PDF/                   📕 PDF کتاب/درس (فشرده‌شده)
└── media/                 🎬 ویدیو/صدای درس (V01-03 · A01-03)
```

## قاعده‌ی مهم (منبع ↔ سرور)
- فقط محتوای **PDF/** و **media/** به سرور (Appwrite) ارسال می‌شود.
- پوشه‌های ۰۰ تا ۰۶ **منبع محلیِ ساخت ماژول‌های اپ** هستند (فلش‌کارت، آزمون،
  نکات و…) و هرگز به سرور ارسال نمی‌شوند.
- HTMLهای ۰۱ تا ۰۶ اول ساخته می‌شوند و از روی همان‌ها ماژول‌های مربوط در اپ
  برای هر درس تولید می‌شود.

## فصول ریاضی — R01
هر فصل ریاضی یک پوشه‌ی `Eyy-R01 - جمع‌بندی فصل …` در سطح فصل دارد
(همان اسکلت استاندارد)؛ جزوه‌ی جمع‌بندی بعداً ساخته می‌شود.

## نام‌گذاری
- کتاب: `CXXX` (C901…C941) · فصل: `Eyy` · درس: `Eyy-Lnn` یا `Lnn`
- PDF: `CXXX_[Eyy-]Lnn_BOOK.pdf` داخل `PDF/`
- رسانه: `CXXX-Eyy-Lnn-V01.mp4` / `…-A01.mp3` داخل `media/` (جزئیات: MEDIA-README.md)
- جلد هر کتاب: `cover_CXXX.jpg`
