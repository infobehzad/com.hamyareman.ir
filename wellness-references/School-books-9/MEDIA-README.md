# قرارداد رسانه‌ی درس‌ها (ویدیو/صوت) — پرامپت ۰۱

## نام‌گذاری فایل‌ها (الزامی — همه‌ی اطلاعات: کتاب، درس، نوع، فصل)
```
<کدکتاب>-<درس>-<نوع><فصل>.<پسوند>
C905-L01-V01.mp4   ← ریاضی، درس ۱، ویدیو، فصل ۱
C905-L01-V02.mp4
C905-L01-V03.mp4
C905-L01-A01.mp3   ← همان درس، توضیح صوتی، فصل ۱ … ۳
```
- هر درس: **۳ ویدیو + ۳ صوت** (الان همه placeholder صفر بایتی در `media/` هر درس).
- فصل‌های همنام (01/02/03) در اپ به‌صورت **یک پلی‌لیست** پشت‌سرهم پخش می‌شوند؛
  نشانگر «فصل x از ۳» بالای کنترل‌ها دیده می‌شود.

## پخش، بافر و کش
- پخش **استریم با بافر** از سرور Appwrite است (کل فایل دانلود نمی‌شود).
- سگمنت‌های بافرشده در **SimpleCache فقط روی گوشی** (تا ۵۱۲MB، LRU) ذخیره
  می‌شوند؛ پخش مجدد همان فصل بدون دانلود مجدد انجام می‌شود.
- «ادامه از همان‌جا» = (فصل ذخیره‌شده + ثانیه) — در `chapterIndex` و
  `lastPositionSec` کالکشن `lesson_media_progress` سینک می‌شود.

## آپلود فایل‌های واقعی
1. فایل‌ها را با همین نام‌ها در باکت رسانه (wellness-media) آپلود کنید
   (fileId = نام فایل).
2. در سید/کنسول، `videoUrl` یا `audioUrl` درس را به **فصل اول** بدهید
   (مثلاً `…/C905-L01-V01.mp4`) — اپ خودش 01/02/03 را به پلی‌لیست تبدیل می‌کند.
3. یک‌بار اجرا: `node backend/seed/migrate-prompt-01b-chapter-index.js`
   (ستون chapterIndex — idempotent).
